# Explaining code

1. Read the whole file first with read_file. Never explain from a fragment.
2. Start with one sentence on what the file is *for*, then walk the
   important functions top to bottom.
3. Point at line numbers. Quote at most three lines at a time.
4. End with the one thing most people misread in this code.
