# Sub-theme 04 - OpenUI Lang

OpenUI Lang is the line-oriented language for model-generated UI from the
OpenUI project (`@openuidev/lang-core`, `@openuidev/react-lang`): every
statement is `id = Component(args)`, arguments are positional, references
may point forward, and a renderer can draw the first line before the second
arrives. The State of Generative UI report (June 2026,
https://www.openui.com/blog/state-of-generative-ui-report) places it in the
declarative middle of its generation spectrum and measures it as the most
token-efficient of the open formats. This sub-theme builds the language by
hand, then uses the real packages, then reproduces the report's numbers.

Steps, in order:

1. `step_01_openui_lang_parser` - a small parser for the core of the
   language in Python and in JavaScript, a catalog as plain JSON Schema, a
   hand-written DOM renderer, and a page that streams a program line by line
   with the skeletons of forward references visible.
2. `step_02_openui_react_lang` - the real stack: a Zod catalog through
   `defineComponent()`, the system prompt generated by `library.prompt()`, a
   model streaming OpenUI Lang over SSE into `<Renderer>`. React without JSX,
   bundled once by esbuild (the README says why).
3. `step_03_format_benchmark` - the report's token table recomputed: the
   seven scenarios projected from one parsed tree into OpenUI Lang, YAML,
   Thesys C1 JSON and json-render's element map, counted with `tiktoken`
   (`o200k_base`), with time-to-first-render at 60 tokens per second and an
   explicit account of which numbers reproduce.

Each step is self-contained: `python demo.py` records the README's demo,
`python -m pytest -q` runs offline. From the repository root,
`python run_tests.py genui/04` and `python check_snippets.py genui/04`
cover the whole sub-theme.
