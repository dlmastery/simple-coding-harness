# Course agent entry point

Read `skills/rsi-tutor/SKILL.md` before guiding a learner. It is the canonical teaching procedure. Read the requested lab README and its stated prerequisites. Do not run the whole course at once.

Students use natural language. You create and run implementation code and configuration. Keep learner work in a separate sibling folder, never in a lesson or source-data directory. Keep failures and reports. Stop at the lab's budget and at its learning checkpoints.

Do not describe this repository as proven autonomous RSI. Distinguish a measured task result, a retained skill, an inherited improver, and a fair comparison of improvers. A public final partition is not a secret evaluation service.

When maintaining the course, preserve the user's steering in `../how-did-i-generate-it/rsi/RSI-STEERING-AND-RESTART.md`. Keep the reusable authoring skill in `../skills/build-research-codelabs/` complete. Follow the current implementation record and update provenance when changing the course.
