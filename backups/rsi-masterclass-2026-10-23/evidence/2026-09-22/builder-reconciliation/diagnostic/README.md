# Generated bike harness

Ask your coding agent to read TASK.md, WORKFLOW.md, and RECOVERY.md, locate the recorded source clone, and run one declared recipe in a new output folder. The agent handles Python setup and commands. The run entry accepts run, compare, or final, plus repository and workspace paths. Task bike and a ten-attempt limit are fixed in generated code.

This package imports the course's shared tools; it is not a standalone replacement for the repository. Its tests are replayed by the retained harness-stage driver. See ACCEPTANCE.md.
