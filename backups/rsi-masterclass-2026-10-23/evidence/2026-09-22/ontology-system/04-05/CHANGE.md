# Version the prediction request

Version 1 estimates a recorded hour with observed weather permitted. Version 2 asks for tomorrow's noon demand using information available by noon today. The target's unit can remain rentals per hour, but input availability changes the scientific question.

Do not overwrite v1's definition or relabel its measured MAE as a forecast result. The new version requires archived forecast releases, a time-aware feature join, a declared evaluation design and new evidence after those inputs exist. The three synthetic availability cases test the release-time rule only.

The existing infographic uses a 09:00 origin to illustrate the same rule. The executed fixtures use a 12:00 UTC origin, as stated in VOCABULARY-v2.md and AVAILABILITY.csv. Those are different explicit examples, not conflicting descriptions of one measured run.
