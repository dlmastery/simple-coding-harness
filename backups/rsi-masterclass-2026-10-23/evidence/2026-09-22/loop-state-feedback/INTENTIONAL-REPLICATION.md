# The same recipe can have a different scientific purpose

The historical controller correctly refused an unlabelled linear/calendar repeat after linear and tree. The duplicate added no new recipe. A separate proposed study could intentionally repeat that exact seed and recipe to test deterministic reproducibility, while keeping both observed costs and outputs.

Label such a proposal “intentional reproducibility check: same data, source, model, features and seed.” Declare its budget before execution. If studying seed variation instead, declare the changed seed and appropriate comparison; that is a different design. Do not relabel an accidental repeat as intentional after seeing its result.

This is a written proposal and explanation, not an additional fit. The frozen historical controller refuses duplicates; it should not be silently weakened inside that already completed experiment.
