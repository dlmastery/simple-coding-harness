# Author-guided inheritance walkthrough

This is a constructed teaching exercise for labs 09.03–09.04. It is not an autonomous RSI benchmark, an independent-context comparison, or evidence of general improver superiority.

The failure is concrete: a report can advertise a lower MAE than its saved predictions support. The earlier result-check tests demonstrated that mismatch. A weak improver that trusts the summary can promote an invalid task-skill output.

The authoring agent writes a revised improver that requires the existing prediction-based check before promotion. The evaluator's data, split, MAE calculation, and truth requirements stay fixed. The changed object is the procedure deciding which evidence to inspect before accepting a task-skill revision.

The next author-guided round reads that revised procedure and invokes its required check on a new labelled mismatched-report fixture. The saved trace distinguishes selecting a version, executing its instruction, and making a decision. It cannot establish how an independent autonomous agent would behave without this guidance.

All reported model predictions come from actual earlier fits. The false report is a deliberately altered teaching copy. It is not a new measured result.
