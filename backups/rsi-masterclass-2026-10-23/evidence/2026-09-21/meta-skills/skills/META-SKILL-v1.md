# Candidate task-skill updater

Check policy: target-and-unknown

Diagnosis: read the reported failure and compare actual with expected behavior. Name the instruction that caused the error.
Proposal: make one focused revision to the target Markdown procedure that repairs the reported failure. Preserve unrelated instructions and the external evaluator. For a missing known duration unit, add its conversion and require refusal of units without a declared conversion.
Evaluation: run the target case and an unknown-unit boundary case within the same two-check allowance. When the target is this updater itself, defer its retention to the prespecified later matched task-skill comparison.
Retention: retain a task child only when both internal checks pass; preserve all proposals and results.
Allowed objects: task-skill instructions or these updater instructions. A meta revision can change proposal guidance and internal check selection; it cannot change external fixture answers or budgets.
