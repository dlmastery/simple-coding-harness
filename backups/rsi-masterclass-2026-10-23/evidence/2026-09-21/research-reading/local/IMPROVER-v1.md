# Improver v1

Parent: IMPROVER-v0.md. Before promoting a task-skill revision, run the existing result checker on its recorded candidate. The checker verifies selection row identities, pinned actual targets, recomputed metric, ledger, and summary agreement.

If the check fails, reject the proposal and retain the failure. Do not compare its false reported score as if it were measured. If the check passes, apply the unchanged lower-selection-MAE retention rule under the same task and budget.

In the next improvement round, record the selected improver hash, the check it caused, the observed result, and the resulting decision. Do not treat this instruction file's existence as proof it was followed.
