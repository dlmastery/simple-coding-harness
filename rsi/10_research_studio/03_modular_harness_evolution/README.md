# Local changes and their interactions

[Research studio](../README.md) · [Course](../../README.md)

Diagnose one interface or action from contrasting traces. Restrict the edit, then test how it interacts with a second change. Finish by distinguishing a lineage of changed agents from a lineage of changed improvement procedures.

**Start with:** Bring one valid and one failed workflow trace, versioned harness components, and your solver/improver map. The integration activity uses seven small fixtures and no training.

- [10.10 · Localize a harness problem](step_10_localize/README.md): A failure diagnosis and one restricted edit to a harness component.
- [10.11 · Integrate edits and test transfer](step_11_integrate/README.md): An integration check for two individually tested harness edits.
- [10.12 · Compare agent evolution and improver evolution](step_12_lineage/README.md): A lineage audit distinguishing changed agent code from changed improvement procedure.

**Carry forward:** Keep a localized patch, an integration report, and a typed lineage. These records prepare the nested-research examples without treating every generation as RSI.

Read the source connection in each lab. The required path fits a laptop; actual large-model training is an optional, separately planned extension.
