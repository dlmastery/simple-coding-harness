# Extend what the inner researcher can build

Proposed by the current coding-agent session on 22 September 2026. No fit of
this revision has run. The separate discovery-policy comparison remains frozen.

The earlier development tree for curved regression 1106 retained a quadratic
linear model with selection MAE 0.336272. Its fixed builder supports raw,
pairwise and quadratic features. The public generator includes curved terms;
the author knows that construction. This is a development-informed proposal,
not blind discovery of an unknown law and not a response to final-row scores.

Add a training-fitted spline basis alongside quadratic features in the linear
pipeline. This gives the researcher a candidate it could not previously
produce. Apply it to all input columns without revealing latent coefficients
or selecting columns from the generator's hidden parameter values. Fit every
transform on training rows only. Use linear extrapolation for spline values
outside the fitted range and retain the existing regularized estimator.

Change the linear branch's fourth candidate to use the new basis. Move its
quadratic candidate to the third position, retaining the parent harness's
quadratic option within the same twelve-attempt broad-search allowance. This
replaces one interaction-only regularization probe. Keep other model families,
root selection and branch allocation unchanged.

The two edited components are the pipeline builder and proposal rule. The
external scorer, data roles and resource limits do not change. The candidate
has more features and may overfit, cost more, or hurt transfer. The selection
gate must be able to retain the parent. A lower training error is insufficient.

This is an AIDE-inspired outer coding-agent edit of an executable inner
research harness. The inner search remains a deterministic program. It omits
the source's LLM inner proposal process and does not establish ignition or
sustained recursive improvement. Those differences must remain visible.
