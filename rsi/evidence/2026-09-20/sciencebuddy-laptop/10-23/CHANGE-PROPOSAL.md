# Repair the reporting omission

The classroom request requires visibility into rare high-quality wines. The parent procedure reports only ordinary accuracy. On the complete preserved inputs, that leaves the majority model's zero minority recall unstated.

The child requires both class recalls, balanced accuracy, linked row-level evidence, and a limit statement. It refuses to finish when expected evidence is missing. The fixed rubric, predictions, label rule, and expected selection identities remain unchanged. Parent and child versions remain separate files.

The four paired cases show the interpreter obeying those different instructions. The child completes the full-evidence case and correctly marks the incomplete-evidence case unresolved. It does not manufacture the missing minority rows. This is deterministic reporting-harness adaptation, not a trial of language-model weight learning or an independent comparison of coding-agent prompts. The author wrote the instructions, reporter, and rubric in one context.
