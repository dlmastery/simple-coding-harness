# Keep scientific choices out of accidental implementation decisions

The retained bike brief fixes a retrospective hourly target, pinned source, permitted inputs, chronological partitions, MAE, training-median baseline and two admitted attempts. It also requires retained failures, a CPU default and timed commands. These choices define what the results can mean. Module names and report layout are routine choices for the coding agent.

The metric-omitted copy is an unexecuted counterexample. Two plausible choices are MAE, which averages absolute errors in rentals per hour, and RMSE, which squares errors before averaging and therefore penalizes large errors more strongly. Either can be legitimate for a stated decision problem. Choosing whichever flatters a candidate after seeing both results changes the comparison rather than supporting the original claim.

The source brief resolves the ambiguity before generation by specifying MAE. No alternative-metric fit or retrospective winner selection is performed in this review. Other decisions the builder must make visible include the regularization setting, category encoding, clipping of negative bike predictions and the runtime dependency on course tools. Some are fixed by the supplied tool rather than invented by the builder.
