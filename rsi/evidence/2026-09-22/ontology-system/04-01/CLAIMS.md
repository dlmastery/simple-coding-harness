# Replace an ambiguous improvement claim

| Ambiguous statement | Precise rewrite | Evidence needed |
|---|---|---|
| The model improved | The linear bike candidate had lower selection MAE than the constant candidate under the same calendar inputs, seed and split | Two named candidates, their predictions, checks and comparison; the new 02.01 run supplies these |
| The model improved after editing a skill | The research procedure's written instruction changed; a later run must show whether that change affects decisions or outcomes | Before/after skill identities, an actual later instruction-to-action trace and a fair comparison; the edit alone proves no performance gain |
| The model improved after weight training | A named language model's parameters changed; its quality claim requires comparison on specified evaluation tasks | Weight/checkpoint identities, training records and controlled evaluation; this walkthrough performs no LLM training |

The latter two rows classify possible claims. They do not claim that those events happened in this ontology activity. A task-model fit, a skill edit and an LLM parameter update change different objects.

Replace “score 159.95” with: “The fixed-process 01.02 trial-001 constant/calendar candidate, seed 17, has selection MAE 159.94791188618632 rentals per hour across 4,358 rows from 2012-H1 under its saved bike contract.”

Missing candidate identity can attach a good result to the wrong model. Missing partition can confuse selection with final evaluation. Missing metric can confuse an error, where lower is better, with accuracy, where higher is better. Missing units can make values with different targets appear comparable. These are scientific differences, not formatting preferences.
