# Inspect the course's measured examples

These are author executions, audits, and labelled fixtures. They make examples inspectable. They do not establish that a student completed a lab or that every coding-agent integration works.

Start with the scientific question you want to check:

| Question | Evidence to inspect |
|---|---|
| Does the basic ML workflow run? | [Initial execution record and environment](2026-09-20/README.md) |
| What did the three exploration attempts establish? | [Measured probes and a decision before the final fit](2026-09-21/exploration/README.md) |
| Do the plan, files, and trace tell the same story? | [Three views of one execution](2026-09-21/three-views/README.md) |
| Can a graph reject wrong contracts or inconsistent facts? | [Join, invariant, and renaming cases](2026-09-21/foundation-gaps/README.md) |
| Does a valid score imply a valid memory lesson? | [Actor memory, frozen comparison, and stale-state rejection](2026-09-21/memory-labs/README.md) |
| What can replay answer, and when must we fit again? | [Discovery tree, missing coverage, and online comparison](2026-09-21/dream-labs/README.md) |
| Does a harness edit repair a model interface? | [Format compatibility comparison](2026-09-21/model-harness-fit/README.md) |
| Can two individually passing edits fail together? | [Context repair, rejected integration, and typed lineage](2026-09-21/modular-labs/README.md) |
| Does a better ML researcher become a better improver? | [Four-fit search, matched outer comparison, and separate role fixtures](2026-09-21/aide-labs/README.md) |
| Did the revised updater govern a later task-skill change? | [Fixed repairs, inherited check policy, and matched external decisions](2026-09-21/meta-skills/README.md) |
| Can a proposed schedule perform an invalid update? | [Typed operations and scheduler checks](2026-09-21/operator-composition/README.md) |
| Can a candidate exploit information in a reference trace? | [Checked references and rejected shortcuts](2026-09-21/checked-reference/README.md) |

Each report states its inputs, actual actions, measurements, budgets, and limits. Prediction files and source snapshots support the prose. Synthetic scores, replays, author-known cases, and unexecuted proposals are labelled where they appear.

For all 101 labs, use the [required-activity inventory](../../how-did-i-generate-it/rsi/validation/REQUIRED-ACTIVITY-COVERAGE.md). A mapped evidence folder can cover only part of a lab; read its remaining gap. Source reviews, learner assessment, fresh agent contexts, and optional cluster execution remain separate forms of evidence.

These folders are archives. Start your own lab in a separate sibling workspace through its README and tutor skill. Do not modify a recorded run to reset a budget or reopen evaluation.
