# A different allocation rule

Using the measured screen fit/prediction time alone would advance tree: 0.0176001 seconds versus forest's 0.1706012. Tree had worse screening MAE, 79.259565531 versus 73.688599022. This alternate decision uses existing observations and runs zero additional fits.

The timing-only rule selects cheap execution, not the best measured proxy quality. It could discard an idea whose quality benefit appears with more data. That possible full-data effect is not measured for tree here; do not invent a full-condition score or claim the screen ranking was reversed.
