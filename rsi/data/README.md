# Data for the rsi/ series

`adult_sample.csv` - 6,000 rows of the Adult Census Income table (OpenML
"adult" version 2, UCI Adult, CC BY 4.0), stratified by the target with seed
0 by `make_sample.py`. The `target` column is 1 when income is above 50K. It
is bundled so every lesson and every test runs offline; `RSI_FULL=1` asks
`common/data.py` for the full 48,842-row table (network once, then cached
under `~/.simple-harness/rsi/`).

The other curriculum problems need no files: breast cancer, wine and digits
come from `sklearn.datasets`, and problems 5-7 are generated by
`common/synth.py` from the seeds in `tasks/*.json`.

`python rsi/data/make_sample.py` regenerates the sample (network).
