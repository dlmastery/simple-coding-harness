# Course migration

The old course is preserved at [commit eed9cbb](https://github.com/dlmastery/simple-coding-harness/tree/eed9cbbdf19c665ae54646253f303be85030798c/rsi). The rebuilt course has one sequence in themed directories. Do not combine its generated workspaces with the old per-step skill packs.

| Old material | New location or treatment |
|---|---|
| Intent and regular harness | Themes 00 and 01: task, evidence, process, skills |
| Loop harness | Theme 02: feedback, state, budgets, restart |
| Graph harness | Theme 03: dependencies, branches, joins, cycles, recovery |
| Missing domain layer | Theme 04: ontology, relations, invariants, semantic failures |
| Missing coordinated-system layer | Theme 05: fixed skills, tools, state, routing, ablations |
| Meta-generated loop and graph | Theme 06: brief, generation, execution, refusal, task transfer |
| Persistent-memory RSI claims | Theme 07 separates persistence, use, benefit, and recursion |
| Proof and meta-RSI | Themes 08 and 09: fair measurement and inherited improvers |
| Dream, RSIAgent, ModularRSI, AIDE², meta-skills | Themed research studios with source-scoped adaptations |
| Single final terminology map | Glossary plus separate self-* experiments and quizzes |
| Duplicated agent skill folders | One canonical `rsi/skills` tree and adapter guidance |
| Flat step tests | Shared behavioral runtime tests and recursive course navigation checks |

Historical offline tests passed before replacement. Their live checks were skipped. The new validation record states which replacement behaviors have run. Passing the historical tests is not evidence that the new course is complete.

The blueprint began with 99 labs. The 20 September research refresh added dedicated MetaRSI and HarnessEvolve activities. The authored sequence now has 101 labs, including 38 research studios in 13 subdirectories. Learning scope, not a target count, motivates the additions.
