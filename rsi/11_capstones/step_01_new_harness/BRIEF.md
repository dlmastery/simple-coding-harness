# Lab 11.01 brief

A runnable harness that another student can inspect and execute.

Starting state: Choose a small permitted tabular dataset, or a new prespecified question on the supplied data. Explain what makes the task new.

Prediction to ask: Which assumption from the bike task is least safe to reuse unchanged?

Execution limit: At most four small CPU fits. No paid cluster launch in the required path.

Follow the README steps. Keep source data and the supplied evaluation contract unchanged. Use the canonical course skills. Generate any required code yourself. Save observations, failures, and the learner’s progress in the separate workspace. Do not invent student answers, measurements, or protected evaluator access.

Acceptance: The handoff is sufficient, evidence is actual, and the refusal is meaningful. A different dataset alone does not establish transfer of every learned procedure.
