# Tools

## Allowed
- read_traces - every fit row of the log so far (scope all)
- read_memory - the actor pack's cards
- read_pack - every file of the actor pack (again after a restore)
- archive - add / list / parent / restore: the variants with their held-out scores
- patch_pack - one rewrite per visit of SKILL.md and loop.json; the private gate, then the human

## Forbidden
- fit_recipe, score_test, save_model - the meta pack never trains and never touches the test split
- write_card - the verifier's tool
