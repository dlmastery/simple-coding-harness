# Tools

## Allowed
- archive - add / list / parent / restore: the variants with their held-out scores
- read_pack - every file of the actor pack (again after a restore)
- patch_pack - one rewrite per visit of SKILL.md and loop.json; the private gate, then the human
- load_splits, fit_recipe, read_memory, score_test, scorecard - the actor's tools, run as the actor pack on the held-out benchmark
- read_traces, write_card - the verifier's tools, run for the verifier pack after each memory arm

## Forbidden
- propose, apply - the meta pack rewrites, it does not generate
- save_model - the models are not the deliverable
