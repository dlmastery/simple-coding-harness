# Skills used in this course

A skill is a written procedure that a coding agent reads and follows. It can tell the agent which tools to call, what evidence to retain, and when to stop. The host agent supplies the language model and execution tools. A skill file alone does not enforce permissions.

| Skill | Purpose |
|---|---|
| [RSI tutor](rsi-tutor/SKILL.md) | Guide one lesson, one observation at a time |
| [Run an ML experiment](run-ml-experiment/SKILL.md) | Execute one declared regression or classification hypothesis |
| [Review domain meaning](review-domain/SKILL.md) | Find contradictions between data, features, splits, and evidence |
| [Improve a research skill](improve-research-skill/SKILL.md) | Propose one procedure change and compare its behavior |
| [Build an ML harness](build-ml-harness/SKILL.md) | Generate a workflow from a readable task brief |
| [Audit an RSI claim](audit-rsi-claim/SKILL.md) | Match the conclusion to the experiment |
| [Scale an experiment](scale-experiment/SKILL.md) | Preserve the task contract while changing compute |

These are the canonical files. Do not keep separately edited Claude, Codex, and Gemini copies. The [adapter notes](../adapters/README.md) explain the file-reading route and native discovery.
