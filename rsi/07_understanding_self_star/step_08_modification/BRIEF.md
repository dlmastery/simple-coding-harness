# Lab 07.08 brief

A versioned edit to a learner-owned procedure with tests and rollback.

Starting state: A learner-owned task skill and its passing and failing cases. Preserve canonical course files.

Prediction to ask: Can a modification make the system worse while still being genuine self-modification?

Execution limit: One edit; two cases checked under both parent and child instructions. At most two new fits in total; use saved predictions when fitting is unnecessary.

Follow the README steps. Keep source data and the supplied evaluation contract unchanged. Use the canonical course skills. Generate any required code yourself. Save observations, failures, and the learner’s progress in the separate workspace. Do not invent student answers, measurements, or protected evaluator access.

Acceptance: The changed surface, parent, child, checks, and active version are recorded. The outcome does not receive an automatic improvement label.
