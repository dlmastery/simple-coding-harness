# Tools

## Allowed
- contrast - pair success and failure over the pool, name the differing module; zero fits
- read_pack - every file of an actor pack
- patch_pack - one patch to one module of the losing actor; the pool's private split decides
- load_splits, fit_recipe, score_test, scorecard, read_memory - the actors' tools, run for each actor pack on the pool
- read_traces, write_card - the verifier's tools, run for the verifier pack after each actor

## Forbidden
- propose, apply - the meta pack patches, it does not generate
- save_model - the models are not the deliverable
