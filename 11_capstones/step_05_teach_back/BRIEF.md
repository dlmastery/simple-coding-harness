# Lab 11.05 brief

A concise portfolio that a peer can run, question, and understand.

Starting state: Your task brief, harness, skills, lineage, results, failure, cost ledger, and claim audit.

Prediction to ask: Which part of your claim would a careful peer find hardest to verify?

Execution limit: One peer reproduction of a small run; no new search to improve the presentation.

Follow the README steps. Keep source data and the supplied evaluation contract unchanged. Use the canonical course skills. Generate any required code yourself. Save observations, failures, and the learner’s progress in the separate workspace. Do not invent student answers, measurements, or protected evaluator access.

Acceptance: The portfolio has runnable evidence and a failed case. The teach-back explains the solver/improver distinction and names remaining uncertainty. Pending peer review is honestly marked.
