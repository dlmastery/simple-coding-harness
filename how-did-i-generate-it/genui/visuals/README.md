Three image calls produced two selected figures. No measured result is drawn
by the generator. The illustrated host window and UI cards are conceptual
examples, not screenshots of named products. The README states that a catalog
format and a delivery protocol require compatible adapters; the figure is not
a universal interoperability claim.
