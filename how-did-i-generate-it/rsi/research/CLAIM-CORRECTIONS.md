# Source corrections and teaching decisions

These are findings from the planning audit. They guide the rewrite but do not claim that the current course was executed end to end.

| Claim or design issue | Correction | Source or evidence |
|---|---|---|
| A later run reads a file, so the system has demonstrated RSI | Persistence alone does not show an improved improvement procedure. Check inheritance, use, and measured effectiveness separately. | [RSI framework](https://arxiv.org/abs/2609.11873) and existing lesson 06 inspection |
| Self-organization and emergence can share one definition | Teach them separately, with examples and counterexamples. Neither alone establishes recursive improvement. | Course terminology audit; definitions still need careful lesson-level sourcing |
| Switching the same session to a verifier role proves blindness | A role prompt does not erase information already available to the agent. Demonstrate the actual boundary. | Existing skill/runtime inspection |
| Any frozen state or approval file is sufficient for a run | Bind checks to the exact candidate, run, and action. | Existing hook inspection |
| Offline document checks demonstrate a working course | Literal-string and mirror checks establish structure. Live execution needs separate evidence. | Existing tests and gated live-test inspection |
| RSIAgent's verifier authors the memory | The actor updates memory after outcome verification. | [RSIAgent](https://arxiv.org/html/2609.15364v1) |
| AIDE²'s improvement claim also proves ignition | Check the outer-improver comparison separately. Its report does not establish statistically significant ignition superiority. | [Weco report](https://www.weco.ai/blog/first-evidence-of-recursive-self-improvement) |
| Dream-RSI replay provides evidence for arbitrary unseen branches | Replay operates over realized history. New online work is needed beyond that coverage. | [Dream-RSI](https://arxiv.org/html/2609.14858v1) |
| ScientistTwo's automated review scores are actual conference acceptances | Its simulated review loop, reported human ratings, and an actual venue decision are different evidence. Do not describe all paper assessments as automated or convert a rating into conference acceptance. | [ScientistTwo](https://arxiv.org/html/2609.19644v1) |
| ScienceBuddy uses one interchangeable form of feedback | Distinguish actual researcher interaction, simulated procedural feedback, and rubric-derived training rewards. | [ScienceBuddy](https://arxiv.org/html/2609.17523v1) |
| A harness efficiency paper demonstrates compounding recursive gains | SoL-Pi describes that compounding use as future work. | [SoL-Pi limitations](https://arxiv.org/html/2609.20519v1) |
| Two successful improvements must combine successfully | Model updates can disrupt an evolved harness's fit. | [On-policy correction study](https://arxiv.org/html/2609.09134v1) |

Before a corrected lesson is marked complete, connect its exact wording to a source and a classroom observation. Keep paper-reported evidence separate from the local exercise.
