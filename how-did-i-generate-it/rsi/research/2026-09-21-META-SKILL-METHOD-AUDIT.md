# What the two-timescale exercise preserves

Selected method reading on 21 September 2026: [MetaSkill-Evolve v1, sections 3.2–3.5](https://arxiv.org/html/2607.05297v1), dated 6 July 2026. This is an older foundation, not a current-month discovery.

The source separates task skills from branch-local meta-skills that configure five roles: Analyzer, Retriever, Allocator, Proposer, and Evolver. The fast loop updates task skills. The slower loop turns several descendant outcomes into a meta-level failure trace, then applies the same pipeline to its own meta-skill files. The method also includes graph-based branch selection and cross-branch inspiration. Its slow update coordinates all five meta-skill files; it is not merely a periodic rename or one extra prompt.

Our exercise preserves the distinction between the changed object and its updater, accumulated task traces, a later inherited updater instruction, and a matched comparison. One coding agent follows a short Markdown pipeline. A fixed driver executes constructed ML workflow decisions. We omit the five independent roles, branch graph, retrieval, learned allocation, multi-file co-evolution, and source benchmarks. These omissions prevent a source-method reproduction claim. Even a local improvement in fixture decisions does not establish broad or sustained RSI.
