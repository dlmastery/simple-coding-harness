# Fresh-session handoff test

Status: executed on 23 September 2026 after the user resumed the prepared test.
See [both outcomes and the context limitation](../fresh-session-results/README.md).
The protocol below is retained. It is not a new efficacy study or learner assessment.

Two sessions receive no parent conversation. Both read the same retained skill.
The complete packet includes TASK.md. The negative packet deliberately omits
it. Neither prompt supplies an expected score or earlier predictions. Shared
filesystem access remains a procedural boundary, not a security sandbox.

## Allocation and actions

1. The complete-packet session reads its handoff and executes exactly one
   constant/calendar baseline, seed 17, in a fresh sibling workspace. The
   attempt limit is one. A failure consumes that allocation. No retry, final
   evaluation or recipe change is permitted. Verify the saved predictions.
2. The missing-task session reads only its packet and identifies the unresolved
   task specification. Its allocation is zero fits. It must not recover the
   missing brief from old evidence, shared memory or the other packet.
3. The parent agent compares actual commands, source/data identities, ledgers,
   reports and predictions with the retained recipe. It records any deviation.
   Every available transcript and output is preserved; skipped learner answers
   remain skipped.

The exact tool source and data identities are recorded before dispatch. Use the
current project Python 3.12 environment. Bound every model command to 60 seconds.
Agent inference is separate and may be unmetered; no cost-efficiency claim follows.
The sessions may inspect dependency instructions, but may not edit repository
source, alter budgets, call other agents, send messages externally or publish.

## What would pass

The complete session reconstructs and runs the fixed procedure from the packet
without historical score targets. The second session recognizes the missing
brief and does not fit. A different model, inferred missing brief, silent retry,
wrong partition or unrecorded parent context is a finding, not something to hide.

This tests a fresh context in the available coding-agent host. It does not
validate every coding agent, independent human comprehension, cluster execution,
autonomous recursive improvement or a positive predictive effect.

## Dispatch requirement

The session's operating rules require explicit user authorization before
launching additional agents. The prepared packets are concrete and reviewable.
The user subsequently resumed this prepared test. Both bounded sessions have
now finished; the separate one-fit allocation is exhausted. Existing model
studies remain closed.
