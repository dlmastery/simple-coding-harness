Teaching point: A course in changing models, research procedures and the procedures that improve them.Begin with a familiar question: how would you improve a modelthat predicts hourly demand? Students will suggest better features or adifferent model. Keep those suggestions. We will later ask how a system choosesamong them, and how it can improve that choice process. The picture introducesdifferent objects that can change. It does not report a measured result.Source: course README and lab 09.01.Course evidence and reading:https://github.com/dlmastery/simple-coding-harness/blob/7db77bd8d38aa5f23dc4180e341de415d6b99296/rsi/README.mdhttps://github.com/dlmastery/simple-coding-harness/blob/7db77bd8d38aa5f23dc4180e341de415d6b99296/rsi/09_recursive_self_improvement/step_01_three_objects/README.mdIllustration: https://github.com/dlmastery/simple-coding-harness/blob/7db77bd8d38aa5f23dc4180e341de415d6b99296/rsi/assets/illustrations/main-overview-v2.pngThe figure explains a mechanism.
