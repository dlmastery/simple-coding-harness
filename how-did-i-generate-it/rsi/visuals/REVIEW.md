# Technical diagram review

Created 101 original schematics from the lesson mechanisms. Mermaid CLI 11.17.0 rendered every diagram successfully in both retained galleries. Render settings: white background, page width 1,200, scale 1.5, two parallel render jobs.

The [first gallery](rendered-gallery.md) used horizontal flow throughout. Visual inspection of diagrams 1, 11, 58, 82, and 94 found readable labels and correct visible arrows, but some chains were too wide for a normal lesson column. The [second gallery](rendered-gallery-v2.md) uses vertical flow for longer sequences and keeps horizontal layouts for useful comparisons. Revised diagrams 11, 33, 55, and 82 were visually inspected for the loop exit, builder/system distinction, inherited action, and grouped-reward explanation. Their labels and paths were legible at displayed size.

All 101 source diagrams were authored against their lesson mechanism and rendered; this is not a claim that every image received an independent visual review. Full learner, narrow-screen, and GitHub dark-mode review remain separate checks. Captions preserve the key meaning outside the image. Static PNG copies make the diagrams available where Mermaid is not rendered.

The renderer emitted Windows backslashes in Markdown image targets. The publishing step normalizes those separators for GitHub. The first attempt to rerender with an exact npm package spec triggered another browser installation and stalled. That owned installer process was stopped. The already installed CLI reported version 11.17.0 and completed the second render. No course run depended on the interrupted installer.

The source galleries and all first/revised PNGs are retained. The published asset manifest records dimensions, hashes, and the revised gallery index for every image. The diagrams are conceptual, not empirical plots. No image is claimed to have been generated by Imagen.
