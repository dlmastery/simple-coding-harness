## Key Mechanisms

**AReaL-RSI:**
- Leader agent selects research orientations
- Conditional memory distinguishes resolved vs unresolved findings
- Evidence-based review revises skills between campaigns

**SwarmRSI:**
- Feedback-guided mutation refines hypotheses
- Complementary recombination shares partial results
- Recursive evolution integrates both mechanisms
