# 10.09 · Compare Scaling Approaches

**Purpose:** Distinguish AReaL-RSI (leader-follower) from SwarmRSI (swarm evolution).

## Comparison Table

| Aspect | AReaL-RSI | SwarmRSI |
|--------|----------|----------|
| Coordination | Leader + specialist roles | Peer-to-peer swarm |
| Memory | Conditional (resolved/unresolved) | Shared experience |
| Evolution | Evidence-based review | Mutation + recombination |
| Selection | Leader-guided | Competitive |
| Best for | Persistent research programs | Scientific discovery |

## Your Task

Read the paper summaries and complete the comparison table with:
- One key advantage of each approach
- One key limitation of each approach
- When you would choose each approach

## Quiz

**Q1:** When is leader-follower coordination better than swarm evolution?

**A1:** When there's a clear research direction and you need persistent coordination. Leader-follower is more structured and easier to direct toward specific objectives.
