| Metric | Paper | What it measures |
|--------|-------|------------------|
| RSI-Index | RSIGym | Fraction of performance gap closed |
| Steering-split solve rate | Budget RSI | Performance on evaluation proxy |
| Recursive Learnability | R2Orch | Task choice quality |
| Swarm diversity | SwarmRSI | Agent variety in swarm |

## Your Task

For each metric, write down:
- What problem it solves
- When it's useful
- Its limitations

## Quiz

**Q1:** Why do we need so many different RSI metrics?

**A1:** Different RSI systems optimize different objects (harness, policy, workflow, swarm). No single metric captures all dimensions. Each metric focuses on a specific aspect of improvement.
